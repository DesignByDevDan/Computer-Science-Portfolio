This folder contains my coursework, projects, and related artifacts for **CS-360: Mobile Programming** at SNHU.

## Course Overview
CS-360 focuses on:
- Mobile application development fundamentals.
- Android Studio environment setup and usage.
- Implementing core Android components such as Activities, Intents, and Layouts.
- Best practices for UI/UX design and performance optimization.
- Project-based learning with real-world app concepts.
