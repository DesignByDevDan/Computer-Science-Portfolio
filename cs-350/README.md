
# CS-350 — Embedded Systems / Raspberry Pi (Simulated Submissions)

This folder contains my coursework for CS-350. Because of a Raspberry Pi hardware issue I performed and documented all labs using simulation-capable artifacts (scripts, videos, diagrams, and reports).

## Contents
- `Milestones/` — milestone folders with lab deliverables (code, screenshots, demo videos).
- `Modules/` — module labs, additional assignments and writeups.
- `FinalProject/` — final thermostat project: simulation script, demo video, state machine diagram (PDF & draw.io), and report.
- `assets/` — images, schematics, and other supporting files.

## How to view / run
- Demo videos (`.mp4`) can be played in the browser or QuickTime.
- `Thermostat.py` is a simulation-capable script — it prints LCD/LED/UART output to the console to replicate behavior when hardware is not available.
- `state_machine_fixed.drawio` is an editable diagram that can be opened in https://app.diagrams.net.
